Introduction

Welcome to the AdChain Publisher SDK. Using our ultra-lightweight client library (< 12KB), you can seamlessly integrate transparent Web3 ads onto your existing website and earn instant ETH and ADC token payouts directly to your registered wallet address.

Fast & Lightweight
Zero dependency bundle optimized for Core Web Vitals.

Dual Monetization
Receive payouts in both ETH and ADC tokens.

Installation

Add the AdChain Client SDK to the <head> section of your HTML document: 

<!-- AdChain Web3 Ad Network SDK -->
<script src="https://cdn.adchain.network/sdk.v2.js" async></script>

Authentication & Configuration

Every publisher receives unique API Keys from the dashboard. Configure your credentials before loading the slots: 

<script>
  window.adChainConfig = {
    apiKey: "YOUR_PUBLISHER_API_KEY",
    publisherWallet: "0xYourWalletAddress...",
    network: "sepolia",
    autoTrackViews: true
  };
</script>

HTML Integration

Place responsive ad slot containers anywhere in your web layout: 

<!-- Responsive AdSlot Container -->
<div class="adchain-slot"

Slot Configuration Parameters

Customize slot behavior and presentation using declarative data attributes:

Attribute Allowed Values Description
data-ad-size 300x250, 728x90, 160x600, fluid Specifies the dimensions of the rendered video or banner ad slot.
data-ad-theme dark, light, auto Configures glassmorphic or solid container styles.
data-ad-id string (custom name) Unique identifier used for revenue segmentation in your analytics.

REST Reporting API

Fetch programmatic impression and earnings metrics using our authenticated REST endpoints: 

curl -X GET "https://adchain.network/api/v1/publisher/stats" \
     -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json"
