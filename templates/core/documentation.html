Publisher SDK Documentation

Integrate our decentralized ads into your content channels and start earning in minutes 🚀

Introduction

Welcome to the AdChain Publisher SDK. Using this client library, you can easily host targeted video ads on your websites, verify user view times, and accrue dynamic token rewards settled on the blockchain ledger. The SDK is lightweight, responsive, and cross-browser compliant.

Installation

Insert our core analytics client script tag inside your HTML pages <head> block:

<script src="https://cdn.adchain.net/sdk/v1/sdk.min.js"></script>
Authentication

Generate a unique API key from the active publisher dashboard. Link this token inside your configuration object on load:

<script>
   window.AdChainConfig = {
       apiKey: "YOUR_PUBLISHER_API_KEY",
       publisherWallet: "{{ wallet_address|default:'0x000...000' }}"
   };
</script>
HTML Placement

Embed ad banner containers anywhere inside your HTML structure. The library auto-resolves active frames on load:

<div class="adchain-slot" data-ad-size="300x250" data-ad-id="campaign-header"></div>
Customization

Customize layout behaviors using dataset elements:

Attribute Supported Values Description
data-ad-size 300x250, 728x90, 160x600 Dimensions constraint values.
data-ad-theme light, dark Visual container colors matching target site theme.
Query Statistics

Query live performance logs programmatically using curl headers:

curl -H "Authorization: Bearer YOUR_API_KEY" https://adchain.net/api/v1/stats
FAQ
How quickly do earnings reflect?

Balance aggregates update instantly once the AI verification oracle confirms view compliance logs.

Can I link multiple sites under one API Key?

Yes, you can register and authorize multiple target domain endpoints inside dashboard parameters.
