Publisher SDK Documentation

Integrate our Ads into your website and start monetizing in minutes 🚀

👋 Introduction

Welcome to our Publisher SDK. Using this SDK, you can easily integrate ads on your website and earn revenue. The SDK is lightweight, customizable, and works seamlessly across devices.

📦 Installation

Add our script to your website's <head>:


<script src="https://cdn.myad.com/sdk.js"></script>

🔑 Authentication

Every publisher gets a unique API Key from their dashboard. Use this key to authenticate and load ads on your site. 


<script>
   window.myAdConfig = {
       apiKey: "YOUR_API_KEY",
       publisherId: "PUB123456"
   };
</script>

⚡ Integration

Place ad slots anywhere in your HTML:


<div class="ad-slot" data-ad-size="300x250" data-ad-id="banner1"></div>

The SDK automatically detects .ad-slot elements and fills them with ads.

Example Output:
[Ad Banner 300x250]

🎨 Customization

You can control ad behavior using data-* attributes:

AttributeValuesDescription
data-ad-size300x250, 728x90, 160x600Set ad dimensions
data-ad-themelight / darkChoose ad theme
data-ad-idunique nameUnique slot identifier

📊 Reporting

Fetch real-time ad stats using API:


curl -H "Authorization: Bearer YOUR_API_KEY" \
https://api.myad.com/v1/stats

Example response:


{
   "impressions": 12345,
   "clicks": 678,
   "revenue": 45.67
}

❓ FAQ

Q: How long does it take to start showing ads?

A: Ads usually start appearing within minutes after integration.

Q: Can I use multiple ad slots?

A: Yes, just add multiple div.ad-slot elements.
